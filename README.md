# Transport data platform

Projekt platformy danych transportu miejskiego dla Krakowa: historia GTFS
i GTFS-Realtime, analiza prognozowanych opóźnień oraz jakości danych.

Obecnie repozytorium zawiera narzędzie do pobierania i profilowania feedów
oraz wyniki krótkiego badania A/M/T. Pierwszy przepływ platformy powstanie
dla autobusów Mobilis. Szacowanie przedziałów przyjazdu ze stanów pojazdu
pozostaje przedmiotem walidacji.
